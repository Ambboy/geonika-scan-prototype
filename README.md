# Геоника · реальный 3D-скан

Исследовательский прототип: настоящий цветной скан объекта в браузере. Прокрутка ведёт камеру по демонстрационному маршруту, а режим свободного осмотра позволяет рассмотреть облако самостоятельно. Это отдельный прототип, не замена существующего сайта компании.

## Что показано

- Исходные измерения: **97 486 182** точки внутри и **49 524 269** снаружи.
- Для веб-показа используется облегчённая детерминированная выборка обоих LAS, а не исходные многогигабайтные файлы.
- Цвет взят из реальных RGB-каналов скана. Здания и помещения не синтезируются.
- Точные размеры, количества, границы и контрольные суммы подготовленных данных находятся в `public/data/manifest.json`.
- Координаты источника сохранены, вертикальная ось — Z. Наличие известного геодезического CRS не заявляется.

## Управление

- Прокрутка страницы — вперёд и назад по маршруту.
- Кнопки глав — переход к выбранному виду.
- Свободный осмотр — вращение и приближение сцены вместо управления маршрутом.
- Доступные настройки сцены и режимов подписаны в интерфейсе; состояние загрузки и ошибки не скрываются.

## Запуск и сборка

Нужен Node.js, совместимый с закреплённой версией Vite (см. `package.json`).

```sh
npm ci
npm test
npm run dev -- --host 127.0.0.1
```

Проверка подготовки данных:

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
python3 tools/prepare_scan.py --help
```

Production-сборка:

```sh
npm run build
```

Результат — `docs/`. Пути ресурсов относительные: сборка предназначена в том числе для GitHub Pages под именем проекта, а не только для корня домена. Сайт статический: серверный backend, ключи API и внешние CDN не нужны.

## Данные и воспроизводимость

Бинарный формат описан в `PROJECT_BRIEF.md`; `tools/prepare_scan.py` создаёт выборку из исходного архива. Для подготовки нужны Python 3.10+, NumPy и системная libarchive. Для просмотра и сборки сайта Python не нужен.

Оригинальный архив в Git не включён. Для повторной подготовки нужен отдельно сохранённый исходник; все локальные пути задаются аргументами:

```sh
python3 -B tools/prepare_scan.py \
  --archive /path/to/las.7z \
  --extract-dir /path/to/private/extracted \
  --output-dir public/data \
  --evidence-dir /path/to/private/evidence \
  --expect-archive-sha256 99cbfbba2cad6874c05189fa1d6803499a172d6cbc1409d106cad5c7514aa14a \
  --exterior-points 600000 --interior-points 900000 \
  --seed 20261107 --chunk-points 1000000
```

В каждой равной индексной страте исходника выбирается одна существующая точка. Это не первые N записей; результат воспроизводится при изменении размера чанка. Никаких ссылок скачивания из личной почты или учётных данных скрипт не содержит.

## Публикация

Репозиторий: https://github.com/Ambboy/geonika-scan-prototype

GitHub Pages публикует **проверенную production-сборку** из `main:/docs`. Одного изменения `src/` недостаточно: перед push нужно пересобрать `docs/`, проверить тесты и обновлённые ассеты. Не добавляйте исходные LAS/архивы, частную переписку, токены, персональные данные или локальные отчёты.

Скан размещается публично с отдельного разрешения владельца для этого прототипа. Веб-показ не защищает исходные публикуемые точки от скачивания. Разрешение на просмотр прототипа не является отдельной лицензией на повторное использование скана.

## Границы прототипа

- Маршрут демонстрационный: это не проверенный путь человека через конкретные двери и не навигация с коллизиями.
- Пропуски измерений, скрытые поверхности и объекты за пределами съёмки не дорисованы.
- Облегчённое облако не предназначено для геодезических измерений.
- Автоматическая проверка мобильного viewport не заменяет ручную приёмку на физическом iPhone/Safari.
- Прототип не содержит форм отправки, аналитики, выдуманных отзывов и неподтверждённых коммерческих обещаний.
