# Геоника — прототип просмотра реального 3D-скана

## Результат

Полноэкранная интерактивная сцена: прокрутка страницы управляет камерой по демонстрационному маршруту «снаружи → внутри». Отдельный режим свободного осмотра позволяет вращать, приближать и рассматривать облака. Используются только измеренные точки из предоставленных LAS, не выдуманная геометрия и не подмена сцены видео.

Это отдельный исследовательский прототип, а не замена существующего B2B-сайта «Геоники». Публикация реального скана в открытом доступе через GitHub Pages отдельно разрешена владельцем для этого прототипа. Исходные архивы, письма, ссылки скачивания, пароли и конфигурация агента не публикуются.

## Данные и контракт

- Внутри: `1_внутри.las`, 97 486 182 точек.
- Снаружи: `1_снаружи.las`, 49 524 269 точек.
- LAS 1.2, PDRF 2, координаты XYZ и заполненный RGB.
- Общая система координат сохраняется: правая, вертикальная ось Z; единицы рассматриваются как метры по масштабу исходного объекта, геодезический CRS не заявляется.
- Для лёгкого первого прототипа публикуется детерминированная выборка, а не исходные 147 млн точек.
- `public/data/manifest.json` описывает все фактически подготовленные файлы.
- Формат `.bin`: без заголовка, 16 байт на точку: little-endian Float32 X/Y/Z (байты 0–11), RGB Uint8 (12–14), 255 (15). `byteLength == pointCount * 16`.
- Поля манифеста: `version: 1`, `coordinateSystem: "right-handed-z-up"`, `sourcePointCount`, `sourceArchiveSha256`, `bounds: {min:[x,y,z],max:[x,y,z]}`, `interiorBounds`, `clouds`.
- Поля cloud: `id: "exterior"|"interior"`, `label`, `file: "exterior.bin"|"interior.bin"`, `sourcePointCount`, `pointCount`, `byteLength`, `sha256`, `bounds`, `format: "xyz-f32-rgb8-stride16"`.
- Манифест загружается относительно BASE_URL: `data/manifest.json`, файлы — `data/<file>`.
- Координаты внутри по исходному заголовку: min `[2.7337548859715,-12.960410910313911,-1.3738530427087121]`, max `[19.43576412577449,7.786501731647591,8.36014716328482]`.
- Координаты снаружи: min `[-29.997999998909044,-33.99599994170666,-13.390999082538482]`, max `[43.3649989634933,25.32199894440174,16.585000272777677]`.

## Приёмка

1. Загружается именно реальная выборка обоих облаков с подтверждённым количеством точек и цветом.
2. Прокрутка вперёд и назад меняет камеру непрерывно, главы доступны кнопками и клавиатурой.
3. Свободный осмотр не конфликтует со scroll-маршрутом; возврат к маршруту работает.
4. Есть загрузка/ошибка/retry, WebGL fallback, responsive layout, reduced-motion и подписанные элементы управления.
5. Production build работает под `/geonika-scan-prototype/` и не требует внешних CDN/ключей.
6. Автотесты, визуальная проверка WebGL и независимое ревью предшествуют публикации.
7. После push проверяются remote SHA/tree, cold clone и реальная HTTPS-страница GitHub Pages с её данными.

## Границы

Маршрут демонстрационный; не заявляет проверенного беспрепятственного прохода через конкретную дверь. Пропуски скана не дорисовываются. Смартфонный Safari на физическом устройстве требует отдельной ручной приёмки. Платные генерации, инфраструктурные изменения существующих сайтов и внешние аналитические сервисы не нужны.
